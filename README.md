# Spotify Clone

A Spotify-inspired music player built with **HTML, CSS, and vanilla JavaScript**. This project recreates the Spotify web-player layout and provides interactive music controls in the browser.

## Live Demo

**[Open the Spotify Clone](https://mainkrsna-dot.github.io/spotify-clone/)**

## Features

- Spotify-inspired dark interface and music-library layout
- Search input for filtering the available music
- Play and pause controls
- Audio playback using local audio files
- Custom SVG icons and separate CSS files for the interface
- Responsive player layout

## Tech Stack

- HTML5
- CSS3
- JavaScript (vanilla)
- SVG assets
- HTML audio playback

## Project Structure

```text
spotify-clone/
├── css/       # Stylesheets for the layout and player
├── html/      # Main player page
├── js/        # Player and interaction logic
├── songs/     # Local audio files
├── svgs/      # Icons and SVG assets
├── index.html # Entry point used by GitHub Pages
└── README.md
```

## Run Locally

1. Download or clone this repository.
2. Keep the `css/`, `js/`, `songs/`, and `svgs/` folders in their existing locations.
3. Open `index.html` in a browser. If your browser blocks local audio or file access, run a simple local server from the project folder (for example, VS Code's Live Server extension) and open the local URL it provides.

## Notes

- Audio tracks are loaded from the project's local `songs/` directory, so keep the folder structure intact.
- This is a learning and portfolio project inspired by Spotify's interface. It is not affiliated with or endorsed by Spotify.
