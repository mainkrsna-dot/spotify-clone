# Spotify Clone

A Spotify-inspired music player web application built using HTML5, CSS3 and JavaScript.

## Features

- Spotify-inspired user interface
- Responsive music player layout
- Music library and song sections
- Interactive play controls
- Audio playback
- Custom SVG icons
- Local audio file support

## Technologies Used

- HTML5
- CSS3
- JavaScript
- SVG

## Project Structure

```text
spotify-clone/
├── css/
├── html/
├── js/
├── songs/
└── svgs/
```

## How to Run

Open `html/index.html` in your web browser to run the application.
